# Huella — Demo 7DStudio

Demo ficticia de peluquería canina integrada en el proyecto Astro principal.

- Página: `/demos/huella/` (`src/pages/demos/huella/index.astro`).
- Componentes, estilos y scripts independientes en esta carpeta.
- Recursos públicos: `public/demos/huella/`.
- Datos y créditos: `data/site.json`.
- Enlace desde el catálogo: `src/data/projects.ts`.

Conserva el diseño original de Huella. Los datos de contacto y las opiniones
pertenecen a la demostración, no a un negocio real. La página tiene `noindex`
y queda fuera del sitemap de 7DStudio.
