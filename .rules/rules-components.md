# Componentes

- Crea componentes para secciones independientes, bloques realmente reutilizados o funcionalidades con lógica o interacción propia.
- Extrae bloques cuando compartan estructura y comportamiento, no solo apariencia.
- Props para diferencias concretas, sin variantes futuras.
- No extraigas títulos, iconos, wrappers o botones de único uso sin responsabilidad concreta.
- Un botón reutilizable con comportamiento o variantes comunes sí puede ser componente.
- Mantén juntos HTML, estilos e interacción relacionados.
- No dividas por número de líneas; identifica responsabilidades independientes.
- Listas con diferencias de texto, imagen o enlace: estructura reutilizada alimentada por datos.
