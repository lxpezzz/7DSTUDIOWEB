# Archivos y fases

- Crea archivos necesarios para la tarea y fase actuales.
- No prepares funcionalidades futuras, componentes vacíos, helpers, hooks, estilos o abstracciones por iniciativa propia.
- Puedes preparar rutas o archivos pendientes si el usuario lo solicita expresamente.
- No completes fases futuras fuera del alcance autorizado.
- Cada archivo debe tener una finalidad concreta.
- En auditorías, distingue errores actuales de pendientes deliberados de futuras fases.
- Revisar una demo no exige terminar la web definitiva.
